# Car Racing Game

This is a simple car racing game built using Python and the Pygame library. The game features a scrolling road background, a car that can be controlled by the player, and a dashboard displaying speed, distance, and elapsed time.

## Features

- **Start Screen**: Displays a start button to begin the game.
- **Car Controls**: Use `W`, `A`, `S`, `D` keys to accelerate, move left, brake, and move right.
- **Pause and Stop Buttons**: Pause or stop the game using on-screen buttons.
- **Dashboard**: Displays speed, distance traveled, and elapsed time.
- **Scrolling Background**: Simulates movement with a scrolling road background.

## Requirements

- Python 3.x
- Pygame library
